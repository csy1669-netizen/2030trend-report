# 2030 트렌드 포맷 리포트

MLB 마케팅 인턴 과제 · 채승룡 — AI를 활용한 2030 트렌드·밈 발굴 및 MLB 콘텐츠 제안

## 열기

- `index.html` 하나로 동작하는 단일 페이지입니다. 브라우저로 바로 열거나 GitHub Pages(Settings → Pages → `main` / root)로 배포하면 됩니다.
- 폰트는 Google Fonts(IBM Plex Sans KR · Gothic A1 · IBM Plex Mono)에서 불러옵니다. 오프라인에서는 시스템 폰트로 표시됩니다.

## 구성 (상단 탭)

| 탭 | 내용 |
|---|---|
| 01 분석 흐름 및 기준 | 5단계 흐름, 4가지 기준(볼륨 30 · 반응 30 · 확산 20 · 최근성 20), 측정 조건 |

## 데이터 기준

- 기간: 2026.04.16 – 10.16 (인스타그램 키워드 검색 상위 24개 게시물, 해시태그 누적 게시물 수)
- 키워드 3,110개 → 측정 약 480개 → 조건 통과 323개 → 포맷 13종 → TOP 6 심층 분석(게시물 612건)
- 6위 음식·디저트(6.948)와 7위 마이크로웹사이트·AI·게임(6.946)은 소수점 셋째 자리로 순위를 정했습니다.
- 반응 점수는 검색 상위 24개 게시물의 좋아요 + 댓글 기준입니다. 리포스트는 TOP 6 심층 분석에서 2차 확산 지표로 따로 측정했습니다.
